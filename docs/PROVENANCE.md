# Provenance

The demo scenarios were written for this sample: Alex, Jamie, Mossport, its venues, the book, article vignette, and plans are invented. They are not real itineraries with names replaced. No personal messages, imported catalogs, third-party articles, photographs, or production screenshots are included.

Search, visibility, plan validation/versioning, session signing, and file-persistence mechanisms were adapted from an existing personal application. This repository has separate history. Unused production migrations, provider operations, password administration, and deployment adapters were removed. The local HTTP harness, seed, and interface were created for the sample with AI assistance.

Screenshots show the sample’s normal light theme with generated demo content. Original code and content use the MIT license. The bundled Source Serif font retains its SIL Open Font License and attribution in [third-party notices](../THIRD-PARTY-NOTICES.md).
